============================================================
 Arona-rs —— 碧蓝档案 QQ 机器人（OneBot 独立模式）
 原版 arona 的 Rust 移植版，完全剥离 Mirai / JVM
============================================================

【这是什么】

Arona-rs 是开源项目 arona（Kotlin + Mirai 插件）的 Rust 重写版本，只保留
OneBot 11 独立运行模式。产物没有 JVM、没有 Mirai 控制台、没有插件目录，
一个 exe 直接跑。

  - 项目仓库：https://github.com/YuLinLoli/Arona-rs
  - 上游原版：https://github.com/diyigemt/arona
  - 开源协议：GNU AGPLv3（详见下一页许可证）

【功能一览】

  抽卡      /单抽  /十连  /狗叫  /历史  /抽卡服务器 日服|国服|国际服
  名片      /游戏名  /谁是  /谁叫  /叫我
  娱乐      /塔罗牌 [牌名]
  攻略      /活动 [日服|国服|国际服]   /攻略 <关键词>
  管理      /arona status|services|service list|version|help
            /config  /任务  /备份  /恢复  /抽卡    /紧急停止
  推送      每天 8:00（可配置）推送三服活动日历；活动结束前 5 小时 / 1 小时
            各提醒一次；学生生日并入日历展示
  管理面板  图形界面里开关群功能、维护成员黑名单、热更新 OneBot 连接配置、
            查看实时日志、切换白天/黑夜外观、查看「关于」页面
            （启动参数加 --nogui 可只开命令行黑窗口）

图片（抽卡结果图 / 活动日历图）由 Rust 自己绘制，不依赖 Java AWT；
系统没有中文字体时会自动降级为文本输出。塔罗牌图沿用原版方案从 CDN 下载。

【运行环境】

  - Windows 7 SP1 / Windows Server 2008 R2 SP1 及以上，64 位
    （Windows 10 / 11、Windows Server 2016+ 推荐）
  - 无需安装 .NET / Java / VC++ 运行库，运行库已静态链接进 exe
  - 需要自行准备一个 OneBot 11 实现（如 NapCat、Lagrange）并提供 QQ 账号

【关于 CPU 软件渲染依赖】

  默认的「完整安装」会一并安装 softgl\ 目录（约 62 MB，Mesa llvmpipe），
  这是管理面板的 CPU 软件渲染后端：

  - 正常带显卡的 Windows 10/11 会优先用硬件渲染（OpenGL / DirectX 12），
    这份依赖平时不会被加载；
  - Windows Server、虚拟机、没有显卡驱动或没有 DX12 的机器上硬件后端会失败
    甚至静默卡住（wgpu 在部分服务器上既不报错也不出窗口），程序带「卡死
    看门狗」：超时即换下一个渲染后端，最后自动切到这套 CPU 渲染把管理面板
    画出来，所以服务器上也能正常开 GUI，不需要额外装任何驱动。

  它和 exe 是分开存放、安装时释放的。如果只在正常带显卡的 Windows 10/11 上使用，
  可以在安装向导里选「自定义安装」把它取消掉，省下 62 MB；取消后这些机器上
  GUI 会退回命令行模式，机器人功能不受影响。

【关于管理员权限（UAC）】

  主程序（arona-rs.exe）启动时会自动申请管理员权限（弹 UAC），因为机器人需要写
  数据目录、监听端口、必要时替换 softgl\ 下的渲染 DLL，以管理员身份运行可以避免
  「启动没反应」「保存配置失败」「监听不了端口」等问题。

  - 弹窗中点「是」即可正常使用；
  - 点「否」或提权失败时程序仍会以普通权限继续运行，功能不受影响，
    只是可能因为权限不足写不了数据或监听不了端口；
  - 安装包本身是按用户安装的，安装过程不需要管理员权限，提权只发生在主程序启动时；
  - 调试 / 自动化场景可以设置环境变量 ARONA_NO_ELEVATE=1 跳过提权，
    也可以右键 exe →「以管理员身份运行」，效果相同。

【安装后怎么用】

  1. 安装完成后启动「Arona-rs」管理面板。
  2. 右上角「外观」可以切换白天 / 黑夜模式（白天黑字、黑夜白字，选择会记住）。
     主程序固定叫 arona-rs.exe，程序升级直接覆盖这个文件即可，路径不用改。
  3. 在「OneBot 配置」标签页里添加连接（正向/反向 WebSocket、正向/反向 HTTP），
     填好机器人 QQ 号与连接参数，保存后连接会自动热重载。
  4. 在「群配置」标签页里给需要的群开关功能、维护黑名单。
  5. 让 OneBot 实现连接上来，在群里发 /帮助 即可。

  数据目录：安装目录下的 arona-standalone/
     onebot.yml        OneBot 连接配置 + 图片发送方式(send_image_as_file)
     arona.yml         业务配置（群、管理员、推送）
     gui.txt           界面外观（白天 / 黑夜）
     data/arona.db     数据库（群名片、抽卡记录、黑名单等）
     logs/             按天滚动的日志
     images/           活动日历等本地图片缓存
     backups/          备份文件

  安装时已释放一份默认配置；如果文件缺失或内容损坏，程序启动时会按内置默认值
  自动补齐，不会因为配置问题起不来。

【以后怎么更新】

  安装程序会把安装目录写进注册表：

     HKEY_CURRENT_USER\Software\YuLinLoli\Arona-rs
       InstallPath        安装目录
       Version            已安装版本
       ExeName            主程序文件名
       UninstallString    卸载程序路径

  （选择「为所有用户安装」时写在 HKEY_LOCAL_MACHINE 下同样的位置。）

  所以下载新版本的安装包后直接运行即可：

  - 会自动认到上面记录的安装目录，装回原位置，不用重新选路径；
  - 会自动跳过「程序简介」和「开源协议」两页，只需一路「下一步」；
  - 配置、数据库、日志、图片全部保留，不会被覆盖。

  也可以在命令行里显式声明这是一次更新安装（装完自动关闭，适合脚本/自动更新）：

     arona-rs-<版本号>-setup-win-x64.exe /VERYSILENT /NORESTART

【卸载】

  从「设置 → 应用」或开始菜单卸载。卸载时默认保留 arona-standalone\
  （配置 / 数据库 / 日志 / 图片），会单独询问是否连数据一起删除。
