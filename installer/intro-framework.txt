============================================================
 Arona-rs —— QQ 机器人框架（OneBot 11 独立运行模式）
 这一版只含框架本体，不附带任何功能插件
============================================================

【这是什么】

Arona-rs 是一个用 Rust 写的 QQ 机器人框架：连上任意 OneBot 11 实现
（NapCat、Lagrange、LLOWeb 等），框架负责收消息、认权限、分命令、管插件，
真正的功能由「功能插件」提供。产物没有 JVM、没有 Mirai 控制台、没有插件目录，
一个 exe 直接跑。

  - 项目仓库：https://github.com/YuLinLoli/Arona-rs
  - 上游原版：https://github.com/diyigemt/arona（Kotlin + Mirai 插件）
  - 开源协议：GNU AGPLv3（详见下一页许可证）

【框架管这些】

  连接      OneBot 11 四种连接形态：WebSocket 正向 / 反向、HTTP 正向 / 反向，
            同一类型可配多个实例；断线自动重连、心跳、token 鉴权、改完热重载
  消息      全谱消息段：文本、@、引用回复、图片、表情、语音、视频、文件、
            戳一戳、位置、XML/JSON、合并转发；出站支持自动撤回
  授权      群白名单、全局用户黑名单、分群功能开关、分群成员黑名单、
            框架管理员名单（arona.yml）
  命令      命令表：别名、用法说明、优先级裁决（多家插件抢同一个命令名时）、
            最短前缀匹配、类型化参数与校验、按群身份门控（成员/管理员/群主）、
            @机器人 后紧跟命令也能命中
  事件      事件总线 + 监听优先级，钩子可短路后续命令分发；每条要说的话在发出去前
            还能被出站钩子改写或拦停；插件的处理器 panic 不会带崩机器人，
            连续失败达阈值自动停用该插件
  聊天留档  框架自己记一份聊天记录（data/arona/chatlog.db，图片只存原链接），
            供插件做「引用回复」与按存储 id 的「撤回消息」；过期记录按配置定时清理
  生命周期  插件四阶段装配（登记 → 装配 → 启动 → 停止），停用即由框架回收它名下
            的命令、事件订阅、定时任务、后台任务与注册服务
  配置      框架配置 config/arona.yml（群授权、管理员、插件开关、框架行为、聊天记录）、
            协议配置 config/onebot.yml，每个插件各有一份 config/<插件>/arona.yml；
            缺文件自动生模板，改文件自动热重载
  定时      内置定时任务内核：每天固定时刻、固定间隔、单次延时三种形态
  面板      图形管理面板（egui）：群管理、插件管理、OneBot 连接、实时日志、关于，
            支持白天/黑夜外观；启动参数加 --nogui 可只开命令行黑窗口

【这一版没有的东西】

功能插件一个都不带，所以装完连上 QQ 之后：

  - 群里发任何命令都不会有人回应 —— 连 /帮助 都没有，因为帮助页、抽卡、攻略、
    活动推送这些全部来自功能插件，框架只提供它们运行所需的骨架；
  - 管理面板的「插件管理」页会是空的，群管理页里也没有可开关的功能项。

想马上有功能，两条路：

  1. 换用带功能插件的构建（当前官方在维护的是碧蓝档案插件：抽卡 / 活动攻略 /
     日程笔记 / 每日推送 / 塔罗牌 等玩法）；
  2. 自己写一个插件：以 `arona` 为依赖实现 `AronaPlugin`，在仓库根目录的
     `plugins.toml` 里登记，然后 `cargo build --release -p arona-host`。
     接口逐条说明见仓库根的 PLUGIN_DEVELOPMENT.md，最小可编译样例见 plugins/hello。

【运行环境】

  - Windows 7 SP1 / Windows Server 2008 R2 SP1 及以上，64 位
    （Windows 10 / 11、Windows Server 2016+ 推荐）
  - 无需安装 .NET / Java / VC++ 运行库，运行库已静态链接进 exe
  - 需要自行准备一个 OneBot 11 实现（如 NapCat、Lagrange）并提供 QQ 账号

【关于 CPU 软件渲染依赖】

  默认的「完整安装」会一并安装 softgl\ 目录（约 62 MB，Mesa llvmpipe），
  这是管理面板的 CPU 软件渲染后端：

  - 正常带显卡的 Windows 10/11 会优先用硬件渲染（OpenGL / DirectX 12），
    这份依赖平时不会被加载；
  - Windows Server、虚拟机、没有显卡驱动或没有 DX12 的机器上硬件后端会失败
    甚至静默卡住（wgpu 在部分服务器上既不报错也不出窗口），程序带「卡死
    看门狗」：超时即换下一个渲染后端，最后自动切到这套 CPU 渲染把管理面板
    画出来，所以服务器上也能正常开 GUI，不需要额外装任何驱动。

  它和 exe 是分开存放、安装时释放的。如果只在正常带显卡的 Windows 10/11 上使用，
  可以在安装向导里选「自定义安装」把它取消掉，省下 62 MB；取消后这些机器上
  GUI 会退回命令行模式，机器人功能不受影响。

【关于管理员权限（UAC）】

  主程序（arona-rs.exe）启动时会自动申请管理员权限（弹 UAC），因为机器人需要写
  数据、监听端口、必要时替换 softgl\ 下的渲染 DLL，以管理员身份运行可以避免
  「启动没反应」「保存配置失败」「监听不了端口」等问题。

  - 弹窗中点「是」即可正常使用；
  - 点「否」或提权失败时程序仍会以普通权限继续运行，功能不受影响，
    只是可能因为权限不足写不了数据或监听不了端口；
  - 安装包本身是按用户安装的，安装过程不需要管理员权限，提权只发生在主程序启动时；
  - 调试 / 自动化场景可以设置环境变量 ARONA_NO_ELEVATE=1 跳过提权，
    也可以右键 exe →「以管理员身份运行」，效果相同。

【安装后怎么用】

  1. 启动「Arona-rs」管理面板。
  2. 在「OneBot 连接」标签页里添加连接（正向/反向 WebSocket、正向/反向 HTTP），
     填好机器人 QQ 号与连接参数，点「保存并热重载」后连接自动生效。
  3. 在「群管理」标签页里把要服务的群加进白名单（留空表示所有群都认），
     需要能改配置的 QQ 号就填进 managers。
  4. 剩下的事需要一个功能插件：没有插件时框架收得到消息，但没有人应答。
  5. 右上角「外观」可以切换白天 / 黑夜模式（选择会记住）。
     主程序固定叫 arona-rs.exe，程序升级直接覆盖这个文件即可，路径不用改。

  运行目录：安装目录本身，配置与数据都在它的子目录里
     config/onebot.yml        OneBot 连接配置 + 图片发送方式(send_image_as_file)
     config/arona.yml         框架配置（群授权、管理员、分群开关、插件开关）
     config/<插件>/arona.yml   插件自己的配置（有插件时才会出现）
     config/gui.txt           界面外观（白天 / 黑夜）
     data/<插件>/             插件数据（数据库、image/ 图片缓存、backups/ 备份）
     logs/                    按天滚动的日志
     plugins/<插件>/          插件清单 plugin.yml（id、名称、版本）

  安装时已释放一份默认配置；如果文件缺失或内容损坏，程序启动时会按内置默认值
  自动补齐，不会因为配置问题起不来。

【以后怎么更新】

  安装程序会把安装目录写进注册表：

     HKEY_CURRENT_USER\Software\YuLinLoli\Arona-rs
       InstallPath        安装目录
       Version            已安装版本
       ExeName            主程序文件名
       UninstallString    卸载程序路径

  （选择「为所有用户安装」时写在 HKEY_LOCAL_MACHINE 下同样的位置。）

  所以下载新版本的安装包后直接运行即可：

  - 会自动认到上面记录的安装目录，装回原位置，不用重新选路径；
  - 会自动跳过「程序简介」和「开源协议」两页，只需一路「下一步」；
  - 配置、数据库、日志、图片全部保留，不会被覆盖。

  也可以在命令行里显式声明这是一次更新安装（装完自动关闭，适合脚本/自动更新）：

     arona-rs-<版本号>-setup-win-x64.exe /VERYSILENT /NORESTART

【卸载】

  从「设置 → 应用」或开始菜单卸载。卸载时默认保留 config\、data\、logs\
  （配置 / 数据库 / 日志 / 图片），会单独询问是否连这些一起删除。
